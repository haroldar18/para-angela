PROYECTO: REGALO INTERACTIVO PARA NOVIA ❤️

1. Abre index.html en un navegador.
2. La primera pantalla muestra el corazón de partículas.
3. Toca la pantalla y aparece la pregunta.
4. "Sí" lleva a una pantalla romántica.
5. "No" activa una cadena de respuestas chistosas.

ARCHIVOS INDIVIDUALES:
- index.html = corazón / introducción
- pregunta.html = pregunta
- si.html = respuesta positiva
- no1.html = primera respuesta al NO
- no2.html = segunda respuesta
- no3.html = respuesta final

IMPORTANTE:
Los archivos son independientes y no necesitan internet para funcionar.
Para enviarlo como experiencia completa, conserva todos los archivos en la misma carpeta.
Para compartirlo por WhatsApp como enlace, hay que publicarlo en un hosting (por ejemplo GitHub Pages, Netlify o Vercel).
